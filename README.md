# data-science-project
## 1. The problem or research question
This project investigates key data patterns through two main analyses:
- How do IQ score distributions and central tendencies compare across different test groups (Group A, B, C, and D)?
- What temporal trends and patterns can be identified in flight passenger volumes or surface temperature anomalies over time?

## 2. Dataset source and usage permissions
- **Datasets**: Includes `iq_scores.csv` and historical flight/temperature datasets.
- **Source**: Provided by the CISC7204 course materials and standard data science libraries (e.g., Seaborn built-in datasets and GISS Surface Temperature Analysis).
- **Permissions**: Utilized strictly for academic study and educational purposes.

## 3. Methods and tools used
- **Language**: Python
- **Libraries**: 
  - `pandas` for data loading, manipulation, and structural transformation.
  - `matplotlib` and `seaborn` for data visualization (such as box plots and customized heatmaps).
- **Techniques**: Group-based statistical comparison, custom color palettes, and axis styling (despining).

## 4. Key findings and one limitation
- **Key Findings**: 
  - The box plot analysis demonstrates clear variations in median IQ scores and data spread across the different test groups.
  - Heatmap visualizations effectively highlight seasonal peaks and long-term upward trends in the temporal datasets.
- **Limitation**: The analysis relies entirely on pre-filtered sample datasets, which may not capture broader external variables or wider population trends.

## 5. Instructions for running the analysis
1. Ensure you have Python, Jupyter Notebook, and necessary libraries installed (`pandas`, `matplotlib`, `seaborn`).
2. Place the dataset files in the designated folder structure (e.g., `../Datasets/`).
3. Open the Jupyter Notebook file (`.ipynb`) in your environment.
4. Run all code cells sequentially from top to bottom to regenerate the data processing steps and visualizations.
